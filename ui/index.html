Phoenix

Browse with an AI agent beside you. Phoenix acts on your requests while you follow its progress.

Get started

  1. Connect an AI provider Checking what is available…
  2. Open a page Type an address or a search above. Search words use the engine chosen in Settings.
  3. Ask about what you are reading Turn on Share page in the chat box, then ask the agent about the tab you have open.

Settings

AI providers

Choose how Phoenix reaches a model. Open a provider to sign in or add a key, pick its model and test it.

Subscriptions

Claude and Codex run through their own command-line clients and reuse the sign-in you already have.

API keys

Keys are stored encrypted for this Windows user and never shown again.

About you

Tell the agent who you are, what you like and dislike and how you work. It uses this in every chat to fit its help to you.

Memory

What Phoenix has learned about you: your details, your answers to questions, your preferences and the choices you make. The agent reads this before it acts and stops asking what it already knows. Correct or delete anything.

Tools (MCP)

Connect MCP servers to give the agent access to tools. Test a server before turning on agent access. Enabled servers are available automatically to supported providers.

Computer use

Let the agent inspect and operate your apps: capture, click, scroll, drag, type, copy and paste. Actions run automatically when enabled.
