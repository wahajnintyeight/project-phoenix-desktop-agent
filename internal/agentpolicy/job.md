Job application guidance: inspect the listing and the user's available resume before tailoring materials. Keep dates, qualifications, and accomplishments accurate. Save useful tailored documents in the file library and export a PDF when needed for upload. Check applications_list for a previous submission before applying. Use browser_fill_form for suitable forms, inspect any remaining required fields, and use browser_upload when an authorized application needs an attachment. Ask for missing answers instead of guessing. Submit only when the user has authorized submission, verify the result, and record confirmed submissions with applications_log. A request to research, compare, draft, or fill an application is not permission to submit it.
